# Estrutura de diretórios compartilhados

A empresa deseja organizar uma área de armazenamento para os diferentes setores.

Crie o diretório principal:

`/empresa`

Configure `/empresa` com permissão `755` (`rwxr-xr-x`), permitindo que os usuários atravessem o diretório principal para chegar aos seus setores.

Dentro dele, crie um diretório para cada setor:

- `/empresa/administracao`
- `/empresa/suporte`
- `/empresa/desenvolvimento`

Configure cada diretório de forma que:

- o proprietário seja o usuário `root`;
- o grupo proprietário corresponda ao respectivo setor.

Ao final, verifique a estrutura criada e as informações de proprietário e grupo de cada diretório.

Utilize os comandos que considerar adequados para realizar e verificar as configurações.

Pressione **CHECK** para verificar esta etapa.
