# Gerenciamento de usuários

Crie os seguintes usuários:

- `ana`
- `carlos`
- `julia`
- `marcos`

Todos os usuários devem possuir um diretório pessoal existente e registrado na conta (por exemplo, `/home/ana` para `ana`).

Associe os usuários aos seguintes grupos:

| Usuário | Grupo |
|---|---|
| ana | administracao |
| carlos | suporte |
| julia | desenvolvimento |
| marcos | desenvolvimento |

A associação pode ser pelo grupo principal ou por um grupo suplementar. Não inclua `julia` em `administracao`, pois ela deverá ter o acesso a esse setor negado na etapa final.

Verifique se as contas e suas respectivas associações foram configuradas corretamente.

Pressione **CHECK** para verificar esta etapa.
